### What I work on

- **Backup operations:** daily monitoring across multiple backup platforms and client
  environments, SLA tracking, schedules, retention, repositories and storage
  optimisation against RPO/RTO targets.
- **Troubleshooting and RCA:** VSS, storage, network and application-aware backup
  failures, with documented root cause analysis.
- **Disaster recovery:** file, SQL, Microsoft 365, VM and bare-metal restores;
  quarterly DR testing and recovery validation; ransomware recovery and resilience
  work (immutable backups, offsite copies, better monitoring).
- **RMM and security tooling:** patching, scripting and remote remediation with
  NinjaRMM, Syncro, Datto RMM and ConnectWise; CyberCNS vulnerability scanning,
  RocketCyber SOC/MDR alert triage, and Liongard documentation and configuration
  drift tracking.
- **Automation and AI:** PowerShell for backup monitoring and alerting; n8n + Claude
  workflows that turn PSA ticket data into client documentation, recurring-issue
  flags and risk insights.
